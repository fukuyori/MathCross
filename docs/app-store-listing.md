## Description

はめこみクロスマスは、数字ブロックを空いたマスにはめこみ、縦横に交差する計算式を完成させる計算パズルです。

ルールはシンプルです。盤面に並んだ式を見ながら、下にある数字や演算子のブロックを選び、正しい場所にはめていきます。横の式も縦の式も同時に成り立つように考えるため、ただ計算するだけではなく、少し先を読む楽しさがあります。

木片をはめるような見た目と手触りを目指し、ブロックを置いたときの反応や音にもこだわりました。完成していない式ではブロックが少し浮き、式が正しく完成するとピタッとはまります。

レベルが進むと、盤面は広くなり、数字だけでなく演算子も考える問題が登場します。困ったときはヒントを使って、未入力の数字をひとつだけ薄く表示できます。

大きな盤面でも遊びやすいよう、下部の数字カードは枚数に応じて見やすく並び替わります。

毎日少しずつ進めても、じっくり考えて一気に解いても楽しめる、落ち着いた計算パズルです。

## English Draft

### App Name

Block CrossMath

### Subtitle

Wooden Number Puzzle

### Promotional Text

Place wooden number and operator blocks into the grid, complete every crossing equation, and enjoy a calm arithmetic puzzle.

### Description

Hamekomi CrossMath is a wooden-block arithmetic puzzle. Place number and operator blocks into empty cells, then complete every horizontal and vertical equation.

The rules are simple, but each move affects crossing equations. Think ahead, use logic, and find the one placement that makes the whole board work.

Blocks feel slightly lifted while an equation is incomplete, then snap into place when the formula is correct. As levels progress, boards grow larger and operator-card puzzles add more depth.

On larger boards, the answer-card tray adapts to the number of cards so the board and cards stay balanced on screen.

Use hints when you need a small nudge, clear levels, and aim for the final celebration.
